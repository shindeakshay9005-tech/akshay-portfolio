# Akshay Shinde Portfolio

Open the folder in VS Code and run `index.html` with the Live Server extension (or just double-click index.html).

```
akshay-portfolio/
├── index.html            page structure
├── css/
│   ├── style.css         main styles
│   ├── loader.css        welcome / loading screen
│   └── chatbot.css       "Ask my assistant" section
├── js/
│   ├── main.js           loader, cursor, animations, tilt, counters
│   ├── chatbot.js        chatbot answers (edit the KB list to add replies)
│   └── contact.js        contact form (opens email app)
└── assets/
    ├── images/akshay.jpg profile photo
    └── docs/Akshay_Shinde_Resume.pdf
```
